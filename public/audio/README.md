# Royalty-Free Audio Tracks

Place the following CC0 / public domain audio files in this directory:

| File | Description | Source |
|------|-------------|--------|
| `happy-birthday.mp3` | Classic "Happy Birthday" melody | Public domain |
| `celebration.mp3` | Upbeat party/celebration track | Pixabay (CC0) |
| `chill.mp3` | Soft ambient/relaxing track | Pixabay (CC0) |
| `romantic.mp3` | Gentle piano track | Pixabay (CC0) |

All tracks must be:
- **CC0 / public domain** licensed
- **MP3 format** (~1-2MB each, keep them small)
- **Loopable** (the player loops the track)

Recommended sources:
- [Pixabay Music](https://pixabay.com/music/) — filter by "Free for commercial use"
- [Free Music Archive](https://freemusicarchive.org/) — filter by CC0
- [Incompetech](https://incompetech.com/) — Kevin MacLeod's royalty-free music

The app references these files at `/audio/{track-name}.mp3`.
